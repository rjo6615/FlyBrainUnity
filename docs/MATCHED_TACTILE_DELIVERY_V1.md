# Matched six-foot tactile delivery v1

Specified before outcomes, 2026-10-24. Question: in the calibrated supported
live-v3 context, does admitting the existing modeled tactile onset candidates
produce downstream neural, mapped motor or physical changes relative to withholding
those candidates? A complete null result is valid evidence, not a reason to tune.

## Fixed paired execution and context

Run WITHHELD then ENABLED, one fresh session each, seed 1, two seconds / 20000
physics transitions / 4000 neural updates per arm. Keep reset and all steps. No
retry, window selection, onset retrigger, stimulus, perturbation, support/collision
change, neural parameter/gain/weight revision, or reference/controller is allowed.
Use the same supported runtime, 20 motor interfaces, six tibia proprioceptive
channels, position control and zero adhesion as the accepted context audit.

Recheck the complete archived live-context evidence and earlier isolated
prerequisite, including their hashes and strict evaluations, before constructing
either session. Require each new model's guarded physical configuration to match
the calibrated context exactly. Prior results and locked sources stay intact.

Use all six complete existing annotation-backed tactile populations (1877 neurons)
and the unchanged `TactileContactEncoder`: threshold 1e-12, maximum modeled rate
120 Hz, linear 20 ms onset pulse, no sustained-contact retrigger. Resolve actual
body IDs and dense indices bidirectionally in the runtime; they must be disjoint
from the 392 proprioceptive neurons and actual motor readout neurons. These are
modeled engineering transduction choices, not measured biological physiology.

Each arm runs the encoder at every physics observation, including reset, with
identically seeded independent per-leg RNGs. Accumulate candidates until the next
neural boundary, preserving the existing set-union semantics. Proprioception is
generated by the existing kernel unchanged. At the neural boundary both arms offer
the union of proprioceptive and tactile candidates through the existing external
drive API at 1000/neural_dt. ENABLED admits eligible tactile events; WITHHELD uses
the runtime's existing external-delivery withholding mask. Endogenous tactile-cell
spikes are not forbidden in WITHHELD. No sensory-to-actuator shortcut is added.

## Prospective common sampling and implementation boundary

Both arms use one fixed sorted external RNG schedule covering the 2269 unique
proprioceptive+tactile indices, drawing one uniform per slot at every neural step.
This is a separately versioned **assay sampling context**, not the ordinary live
runtime's compact eligible-only draw schedule. The eligibility equation and neural
parameters remain unchanged: actual pre-step refractory availability and offered
drive determine trials. Uniforms are drawn before the delivery mask and verified
against expected PCG64 state. Record schedule, uniforms' hashes and RNG state.

Cache actual pre-step refractory availability before calling the original neural
step. This same availability is used in both arms; the legacy withheld-input
shadow refractory clock must not substitute a different eligibility rule. The
runtime still records its shadow clock, but this assay does not use it for event
trials. Different actual refractory states after intervention can change eligible
events; those changes are outcomes, not unequal random draws.

Keep locked kernel/neural/encoder sources byte-identical. The experimental module
uses the kernel's existing factory callback to install two **instance-local**
boundary wrappers: neural `step` (offer inputs and set the mask, then call the
original step exactly once) and external event trials (the fixed draw schedule).
This callback is an experimental intervention installer, not a read-only probe.
No module globals are patched and no second embodiment loop is implemented.
The ordinary live factory and Unity launcher retain their current behavior.

## Predeclared integrity and interpretation

Before delivery: require exact matched initial physical state/configuration,
complete actual neural state (including refractory/adaptation/delay ring/RNG),
motor inventory, observer/decoder state and encoder RNG/state. At every neural
boundary before and including the first eligible tactile opportunity, require
matched pre-step neural state, offered candidates, rates, actual physical state
and common random samples. Verify readout counters against actual brain counts.
Require fixed complete schedules and finite recorded state throughout both arms.

Verify that all eligible non-tactile candidates are delivered in both arms, every
eligible tactile event is delivered only in ENABLED, and no unexpected neuron
crosses the external drive boundary. The gate is the only arm difference. Record
offered, eligible and delivered events separately; a refractory-blocked offered
candidate is not a delivery. Verify the common CNS uniform schedule for the full
window. Encoder candidates/rates must match while the actual physical inputs
match; after physical feedback divergence, input/candidate differences can be
outcomes. Do not demand identical closed-loop trajectories after intervention.

Retain all exact contacts and solver forces with the previous passive recorder.
Reconstruct forces and verify telemetry throughout both trajectories. Any new
unselected direct source, positive calibration-surface force, unsupported source,
changed context, attribution disagreement or nonfinite state makes the run
inconclusive for the calibrated ground-context claim. Continue and preserve the
fixed window rather than filtering, changing encoding, or truncating on failure.
Retain the previous context evaluator unchanged for each arm, including its
per-foot positive/negative coverage criteria. Report a causal loss of that
coverage as context-inconclusive, rather than weakening the earlier gate.

Separate integrity from biological outcomes. Report first eligible tactile event,
first CNS divergence (which can include directly driven neurons), first downstream
state/spike divergence excluding **all 2269 external-input neurons**, first motor
readout/decoder/command divergence, first joint and whole-body divergence, and
contact feedback divergence. Report per-foot offered/eligible/delivered totals and
per-channel motor increments. Do not require activity or movement for integrity
success. If no eligible tactile opportunity occurs, classify NO_ELIGIBLE_TACTILE_EVENTS.
Otherwise classify the furthest observed boundary without claiming useful movement,
balance, gait or biological validation. Preserve partial/error traces with no admission.
